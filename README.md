# SARKER · Premium Guest Generator Web Panel & API

A professional, fully-featured Web Panel and REST API wrapper for the **Guest Generator (`gen.py`)**. This project provides an advanced animated UI for generating accounts and a secure API endpoint for programmatic generation, while keeping the core `gen.py` logic **100% untouched**.

---

## 📂 Project Structure
```text
Guest Generator
    ├── gen.py                  # Original untouched core engine
    ├── app.py                  # Flask server, API routes, and UI wrappers
    ├── requirements.txt        # Python dependencies
    ├── README.md               # This documentation
    ├── templates/
    │   └── index.html          # Main UI template
    ├── static/
    │   ├── css/style.css       # Sakura/Neon theme styling
    │   └── js/app.js           # Frontend logic and live-polling
    └── Guest/                  # Auto-generated by gen.py
        ├── accounts.json       # All generated accounts
        ├── activated_accounts.json # Successfully activated accounts
        ├── activation_results.csv  # CSV log of activations
        └── .panel_tokens.json  # Cached JWTs for instant re-activation
```
---

## ✨ Features

- **Modern UI:** Sakura/Neon themed glassmorphism design with live animations.
- **Auto-Activation Flow:** Generates accounts one-by-one and immediately activates them to prevent token expiry.
- **Live Logs:** Real-time terminal-style logs directly in the browser.
- **Safe Limits:** Hardcoded limits (Max 100 accounts, Max 100 workers) to protect against Garena rate-limits and IP blocks.
- **Data Export:** View and download `accounts.json`, `activated_accounts.json`, and CSV logs.
- **External API (`/gen`):** Generate accounts via URL parameters with beautifully formatted JSON responses.

## 📦 Prerequisites & Installation

> ⚠️ **Important:** `blackboxprotobuf` requires `protobuf==3.10.0`, which might conflict with other global Python packages (like Google Cloud). **It is highly recommended to use a virtual environment.**

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

# 2. Install requirements
pip install -r requirements.txt
```

## 🚀 Running the Application
Start the Flask server:

bash
python app.py
The application will start running on:

Local: http://127.0.0.1:5000

Network: http://<YOUR_LOCAL_IP>:5000

## 🖥️ UI Usage Flow

Open the Web Panel in your browser.

Navigate to the Generate tab from the sidebar.

Set your parameters:

Account Count: (1 to 100)

Region: BD (Bangladesh) - ফিক্সড (অন্য সার্ভার সাপোর্ট করে না)

Nickname: e.g., SARKER (Random digits are automatically appended by the engine to prevent name collisions).

Password Prefix: e.g., MM388401

Workers: (1 to 25 recommended for safety).

Click ▶ Start Generation.

Watch the Live Logs tab for real-time progress. Each account takes ~2-3 seconds to generate and activate.

## 🔗 API Usage (URL Endpoint)
You can trigger the generator programmatically via a simple GET request.

Endpoint
http
GET http://<YOUR_LOCAL_IP>:5000/gen

Example Request
text
http://192.168.0.100:5000/gen?target={2}&thread={2}&region={BD}&name={testuser}&password={mdodj124}&key={yourkey}
